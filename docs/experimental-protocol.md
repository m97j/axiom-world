## Why this file still exists

The repository was restructured at tag `v1.0.1` so that *records* (protocols,
configs, data manifests, closure notes, model cards, diagnostics) are layered by
protocol version, while *machinery* (`src/`, `tests/`, shared scripts, always-on
audits) stays unified. See [`docs/protocols/README.md`](protocols/README.md).

The v1.0 report was published before that restructure and cites this path. A
published, DOI-bearing document must not acquire a dead reference because of a
later reorganisation, so this stub is permanent and must not be deleted.
